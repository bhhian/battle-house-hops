# Battle House Hops Website

**Fresh. Local. Ontario Hops.**

**Live Site:** [https://battlehousehops.ca](https://battlehousehops.ca)

A local recreation of the Battle House Hops website showcasing fresh, quality, local Ontario hops.

## Getting Started

### Quick Start (No Installation Required)

Simply open `index.html` in your web browser:

```bash
# macOS
open index.html

# Windows
start index.html

# Linux
xdg-open index.html
```

### Development Server (Optional)

For a better development experience with auto-reload:

```bash
# Install dependencies (one-time)
npm install

# Start the development server
npm run dev
```

Then visit [http://localhost:3000](http://localhost:3000)

### Alternative: Using npx (no install needed)

```bash
npx serve .
```

Then visit [http://localhost:3000](http://localhost:3000)

## Project Structure

```
battlehousehops/
├── index.html          # Single-scroll home (hero, hops, farm, contact)

```

## Features

- **Responsive Design** - Works on desktop, tablet, and mobile
- **Smooth Animations** - Scroll animations and hover effects
- **Mobile Navigation** - Hamburger menu for mobile devices
- **Modern CSS** - CSS variables, flexbox, and grid layouts

## Hop Varieties

1. **Valley Cascade** - Classic American Pale Ale hop with citrus grapefruit notes
2. **Lanark Centennial** - "Super Cascade" with higher bittering potential
3. **Northern Galena** - High alpha, clean-bittering hop
